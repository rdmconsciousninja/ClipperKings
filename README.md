# Clipper King's Barbershop Website

Modern, responsive web application for **Clipper King's Barbershop** located in Pembroke Pines, Florida.

## Features
- **Barber Services & Pricing**: Detailed breakdown of haircuts, fades, shaves, and beard grooming.
- **Online Booking**: Seamless client appointment scheduling.
- **Barber Profiles & Gallery**: Showcasing precision cuts and master barbers.
- **Location & Hours**: Contact information, maps, and store hours.

## Tech Stack
- **Framework**: React 19 / TanStack Start / Vite
- **Styling**: Tailwind CSS & Lucide Icons
- **Language**: TypeScript

## Getting Started

### Installation
```bash
npm install
```

### Running Locally
```bash
npm run dev
```

### Building for Production
```bash
npm run build
```
